Security Actions

Automated responses executed by cybersecurity detection rules

Rule 1 Unknown Device Detection
High
Action: Alert Generated • Telemetry Rejected

Messages received from unregistered device IDs are immediately rejected and logged as security events. Device is NOT added to the database.

Rule 2 Abnormal Temperature Detection
Medium
Action: Alert Generated • Status Changed to Suspicious

When temperature exceeds the configured threshold, a security alert is generated and device status is updated to Suspicious. Valid sensor data is recorded.

Rule 3 Invalid Sensor Data Detection
Medium
Action: Alert Generated • Payload Rejected

Rejects non-numeric, corrupted, malformed, empty, or unconfigured sensor telemetry. Payload is discarded and not recorded.

Rule 4 Excessive MQTT Message Rate
High
Action: Device Blocked • Messages Dropped

When a device exceeds the message rate limit within the time window, it is blocked for the configured duration. All incoming messages are dropped until the block expires.
